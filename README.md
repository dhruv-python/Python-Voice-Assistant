# Python Voice Assistant 🎙️

## Project Description
Python Voice Assistant is a simple voice-controlled desktop application that listens to user commands and responds through speech.

It uses Speech Recognition and Text-to-Speech technology to perform basic tasks.

## Features
- Voice Recognition
- Text-to-Speech Response
- Greeting Commands
- Current Date and Time
- Google Search
- Voice-Based Command Processing
- Exit Using Voice Commands

## Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3

## Installation

1. Clone this repository:

```bash
git clone https://github.com/ltdhruv1729-design/Python-Voice-Assistant.git
```

2. Open the project folder:

```bash
cd Python-Voice-Assistant
```

3. Install required libraries:

```bash
pip install -r requirements.txt
```

4. Run the project:

```bash
python TheVoiceAssistant.py
```

## Available Voice Commands

| Command | Action |
|---|---|
| Hello / Hi | Greeting |
| Time | Tells current time |
| Date / Today | Tells current date |
| Search for Python | Opens Google search |
| Google | Asks what to search |
| Exit / Quit / Stop | Closes assistant |

## Requirements
- Python installed on your computer
- Working microphone
- Internet connection for speech recognition and Google search
- Speakers or headphones
